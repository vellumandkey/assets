# Vellum & Key — public assets

Public image hosting for Vellum & Key social posts. Instagram and Pinterest can only publish images from a public URL, so the orchestrator uploads finished marketing images here and posts them from their GitHub Pages address:

`https://vellumandkey.github.io/assets/<folder>/<file>.jpg`

| Folder | Contents |
| --- | --- |
| `pins/` | Pinterest pin images (1000 × 1500) |
| `instagram/` | Instagram post and carousel images (1080 × 1440) |
| `facebook/` | Facebook Page post images |
| `etsy/` | Etsy listing images |

Only finished, public marketing images belong here. Never store templates, buyer files, template links or anything private.
